# CLAUDE.md — الموقع الرسمي لفضيلة الشيخ الوالد يحيى بن أحمد الجابري

Arabic website for the lessons, khutab and lectures of **الشيخ يحيى بن أحمد الجابري حفظه الله**, built at the request of the Sheikh's team (so «الموقع الرسمي» is used). Fork of Mohamed-AH/drwasiullah (same engine/design/tests); read `README.md` for the pipeline.

## State (2026-10-04)

Setup: `docs/audio-hosting.md`. Owner runs it when he has bandwidth.
- Deploys: Cloudflare Workers Builds from GitHub; `main` is production, every other branch gets a preview at `<branch>-yahyaaljabri.emah84.workers.dev` (e.g. the `redesign` branch).

## Layout
- `site/` — source (`shell.html`, `styles.css`, `js/core.js` data model + constants, `js/views.js` pages, `js/app.js` browser), `site/data/library.json` (generated by `tools/import_telegram.py`), `site/catalogue.json` (YouTube; empty for now).
- `tools/telegram_lessons.py` (merge/dedupe/title/series, `SERIES` patterns at the top) → `tools/import_telegram.py` → `site/data/library.json`.
- Announcement posters: `site/data/announcements.json` + `site/ann/` (+ `thumb/`), written hourly by `tools/announce_bot.mjs` (Telegram bot, `.github/workflows/telegram-bot.yml`, setup `docs/announcements.md`); shown on the home page and `/announcements/`, hidden after their end date.
- `scripts/build.mjs` pre-renders to `dist/`; `wrangler.jsonc` deploys on Cloudflare.

## Conventions (decided with the owner — keep)
- **Language/direction:** Arabic, RTL. Fonts (self-hosted, OFL): Tajawal for all text; Amiri 700 only for the Sheikh's name in the hero (`amiri-arabic-700-subset.woff2`, subset to Arabic letters with pyftsubset). Digits in titles shown Arabic-Indic.
- **Name:** always the full name «الشيخ يحيى بن أحمد الجابري» followed by «حفظه الله» (the team writes «الشيخ الوالد … حفظه الله ورعاه») (visible on mobile too).
- **Dates:** show **Hijri only** (Umm al-Qura via `Intl`, or the source's own Hijri `hd`). Catalogue Gregorian dates are Riyadh-local (UTC+3) and only used for sorting/conversion.
- **Arabic text never gets `letter-spacing` (must be 0):** Chrome turns off contextual letter forms when it is non-zero, so ي in «الشيخ» vanished in Aref Ruqaa (fixed 2026-10-04).
- **Design:** "Majlis" (chosen by the owner 2026-10-05; replaced the "manuscript library" look): audio first, night green `#0c231c` and brass `#d4ae58`, eight-pointed star (two squares, `STAR`) as mark and pattern. Each page = an optional dark full-width band (`mkPage({band})`) + content in `.wrap`. Series show as square coloured artwork (`art()`, colours `COVER`/`COVER_PALETTE` in `core.js`), lessons as episode rows. A docked player (`#dock`, one `<audio>` in `app.js`) keeps playing across client-side navigation, remembers positions in localStorage, plays the next lesson, sets Media Session. Lesson pages pre-render a native `<audio>` for no-JS and swap it for custom controls (`html.js`). Light + night themes. Icons: Lucide only (no emoji, no hand-drawn icons). Staggered load motion respects `prefers-reduced-motion`.
- **URLs are real paths** (`/series/<id>/`, `/lesson/<id>/`, `/section/<id>/`, `/books/`, `/about/`, `/search/`), never `#/…` (old hash links are redirected by `app.js`). Build links with `href.*` from `core.js`. A new page type = a function in `views.js` + a route in `resolve()` and in `scripts/build.mjs`. A section with one series has no page of its own (it links to the series; the build writes a `_redirects` line).
- **Navigation:** header nav on desktop (≥1180 px); hamburger drawer + bottom bar (≤900 px) with raised centre search button. Sections (`SECTIONS` in `core.js`): التفسير، الحديث، العقيدة، الفقه، الخطب، المحاضرات، التلاوات، الدروس المرئية، الكتب — a section appears only when it has content.
- **Compatibility:** must work on old iOS Safari (iPhone 7, iOS 15): no `<button>` as flex/grid container for centring (use absolute centring), `color-mix()` always with a flat fallback before it, no backdrop-filter on the header (it must be opaque).
- **Safety:** every external string goes through `esc()` before `innerHTML`. **All user input goes through `cleanQuery()`** (length/word caps, control + bidi characters stripped), URL parameters are whitelisted (`oneOf`), route segments use `safeDecode()`, lookup tables are `Object.create(null)`, and every URL from data goes through `safeUrl()` (https only) / `safeYt()`. Run `tests/xss_check.mjs` after touching `app.js`. No third-party scripts. Never commit secrets (`.env` is git-ignored). Don't commit `__pycache__`, wheels, archives.

## Content integrity (important)
- Do **not** invent biographical, fiqh or scholarly content, attributions or translations. Bio/English titles come from the owner or the Sheikh's official sources.
- Only the Sheikh's own lessons belong on the site (the Telegram channels also repost other scholars; `tools/telegram_lessons.py` flags those and `tools/import_telegram.py` leaves flagged lessons out). Don't auto-publish flagged lessons.
- Imported titles/dates come from the source pages; fix data by changing the importer or the source, not by hand-editing generated JSON.

## Testing
`tests/xss_check.mjs`, `tests/e2e.mjs` and `tests/a11y_check.mjs` (see README) must pass after front-end changes; `tests/player_check.mjs` after player changes (needs a build with `MEDIA_JSON=tests/fixtures/media.json`; the test Chromium has no AAC, so it serves an Opus fixture). Verify UI changes with Playwright (Chromium is installed at `/opt/pw-browsers/chromium`): serve `site/`, check desktop 1280 px and mobile 390/414 px, light and dark, zero console errors. Data scripts: run them and spot-check counts. (Planned: axe-core + Lighthouse CI — see roadmap.)

## Known limits of the build environment
Outbound network is allow-listed: YouTube and t.me are **blocked** from the cloud session, so media playback and live data can't be tested there — say so rather than claiming it works.
